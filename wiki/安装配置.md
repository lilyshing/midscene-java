# 安装配置

本章节详细介绍 Midscene Java 的安装步骤、环境配置和依赖管理。

## 📋 系统要求

### 基础要求
- **Java**: JDK 17 或更高版本
- **构建工具**: Maven 3.6+ 或 Gradle 7.0+
- **操作系统**: Windows 10+, macOS 10.14+, Linux (Ubuntu 18.04+)
- **内存**: 最少 4GB RAM（推荐 8GB+）
- **网络**: 稳定的互联网连接（用于 AI 模型调用）

### AI 模型要求
至少需要以下 AI 服务之一的 API 访问权限：
- OpenAI GPT-4V
- Anthropic Claude 3
- 阿里云通义千问 VL
- Google Gemini Pro Vision

## 🚀 快速安装

### 方式一：使用 Maven 安装（推荐）

在你的 `pom.xml` 文件中添加以下依赖：

```xml
<dependencies>
    <!-- 核心模块 -->
    <dependency>
        <groupId>com.midscene</groupId>
        <artifactId>midscene-core</artifactId>
        <version>0.1.0</version>
    </dependency>
    
    <!-- Web 自动化模块 -->
    <dependency>
        <groupId>com.midscene</groupId>
        <artifactId>midscene-web</artifactId>
        <version>0.1.0</version>
    </dependency>
    
    <!-- Android 自动化模块 -->
    <dependency>
        <groupId>com.midscene</groupId>
        <artifactId>midscene-android</artifactId>
        <version>0.1.0</version>
    </dependency>
    
    <!-- 日志依赖 -->
    <dependency>
        <groupId>ch.qos.logback</groupId>
        <artifactId>logback-classic</artifactId>
        <version>1.4.11</version>
    </dependency>
</dependencies>
```

### 方式二：使用 Gradle 安装

在你的 `build.gradle` 文件中添加以下依赖：

```gradle
dependencies {
    // 核心模块
    implementation 'com.midscene:midscene-core:0.1.0'
    
    // Web 自动化模块
    implementation 'com.midscene:midscene-web:0.1.0'
    
    // Android 自动化模块
    implementation 'com.midscene:midscene-android:0.1.0'
    
    // 日志依赖
    implementation 'ch.qos.logback:logback-classic:1.4.11'
}
```

### 方式三：从源码构建

```bash
# 克隆仓库
git clone https://github.com/Python51888/midscene-java.git
cd midscene-java

# 构建项目
mvn clean install

# 或者使用 Gradle
./gradlew build
```

## 🔑 AI 模型配置

### 环境变量配置
创建 `.env` 文件或设置系统环境变量：

```bash
# OpenAI 配置
OPENAI_API_KEY=sk-your-openai-api-key
OPENAI_BASE_URL=https://api.openai.com/v1  # 可选

# Anthropic 配置
ANTHROPIC_API_KEY=sk-ant-your-anthropic-key

# 通义千问配置
DASHSCOPE_API_KEY=sk-your-dashscope-key

# Gemini 配置
GOOGLE_API_KEY=AIza-your-google-api-key

# 默认模型配置
MIDSCENE_AI_PROVIDER=openai
MIDSCENE_AI_MODEL=gpt-4-vision-preview
```

### 应用配置文件

#### application.properties
```properties
# AI 模型配置
midscene.ai.provider=openai
midscene.ai.model=gpt-4-vision-preview
midscene.ai.api-key=${OPENAI_API_KEY}
midscene.ai.base-url=https://api.openai.com/v1

# Agent 配置
midscene.agent.timeout=30000
midscene.agent.retry-count=3
midscene.agent.cache-enabled=true
```

#### application.yml
```yaml
midscene:
  ai:
    provider: openai
    model: gpt-4-vision-preview
    api-key: ${OPENAI_API_KEY}
    base-url: https://api.openai.com/v1
    temperature: 0.1
    max-tokens: 1000
  agent:
    timeout: 30000
    retry-count: 3
    cache-enabled: true
    screenshot-on-error: true
```

### 代码配置
```java
import com.midscene.core.ai.AIModelConfig;

// 多个 AI 提供商配置
AIModelConfig openaiConfig = AIModelConfig.builder()
    .provider("openai")

    .provider("anthropic") 
    .model("claude-3-sonnet-20240229")

    .build();
```

## 🔧 常见问题解决

### Java 版本问题
```bash
# 检查 Java 版本
java -version

# 如果版本低于 17，安装新版本
# Ubuntu/Debian
sudo apt-get install openjdk-17-jdk

# macOS
brew install openjdk@17

# Windows
# 从 oracle.com 下载安装
```

### 依赖冲突解决
```xml
<!-- 在 pom.xml 中排除冲突依赖 -->
<dependency>
    <groupId>com.midscene</groupId>
    <artifactId>midscene-web</artifactId>
    <version>0.1.0</version>
    <exclusions>
        <exclusion>
            <groupId>org.seleniumhq.selenium</groupId>
            <artifactId>selenium-remote-driver</artifactId>
        </exclusion>
    </exclusions>
</dependency>
```

### 网络连接问题
```xml
<!-- 在 pom.xml 中配置国内镜像 -->
<repositories>
    <repository>
        <id>aliyun-maven</id>
        <name>Aliyun Maven Repository</name>
        <url>https://maven.aliyun.com/repository/public</url>
    </repository>
</repositories>
```

### AI API 连接问题
```java
// TestAIConnection.java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;

public class TestAIConnection {
    public static void main(String[] args) {
        String apiKey = System.getenv("OPENAI_API_KEY");
        if (apiKey == null || apiKey.isEmpty()) {
            System.out.println("❌ 未设置 OPENAI_API_KEY");
            return;
        }
        
        try {
            HttpClient client = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(10))
                .build();
                
            HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.openai.com/v1/models"))
                .header("Authorization", "Bearer " + apiKey)
                .timeout(Duration.ofSeconds(10))
                .GET()
                .build();
                
            HttpResponse<String> response = client.send(request, 
                HttpResponse.BodyHandlers.ofString());
                
            if (response.statusCode() == 200) {
                System.out.println("✅ OpenAI API 连接正常");
            } else {
                System.out.println("❌ OpenAI API 连接失败: " + response.statusCode());
            }
        } catch (Exception e) {
            System.out.println("❌ 网络连接错误: " + e.getMessage());
        }
    }
}
```

## 🔄 升级和维护

### 版本升级
```xml
<!-- 升级到最新版本 -->
<dependency>
    <groupId>com.midscene</groupId>
    <artifactId>midscene-core</artifactId>
    <version>0.2.0</version>
</dependency>
```

### 配置备份
```bash
# 备份配置文件
cp application.properties application.properties.backup
cp pom.xml pom.xml.backup

# 导出依赖列表
mvn dependency:tree > dependency-tree.txt
```

### 清理和重装
```bash
# 清理 Maven 缓存
mvn dependency:purge-local-repository

# 重新构建
mvn clean install
```
