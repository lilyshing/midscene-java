## 🔧 安装与配置问题

### Q: 如何在 Maven 项目中添加 Midscene Java 依赖？

A: 在您的 `pom.xml` 文件中添加以下依赖：

```xml
<dependency>
    <groupId>com.midscene</groupId>
    <artifactId>midscene-core</artifactId>
    <version>1.0.0</version>
</dependency>
<dependency>
    <groupId>com.midscene</groupId>
    <artifactId>midscene-web</artifactId>
    <version>1.0.0</version>
</dependency>
<dependency>
    <groupId>com.midscene</groupId>
    <artifactId>midscene-android</artifactId>
    <version>1.0.0</version>
</dependency>
```

### Q: 如何在 Gradle 项目中添加 Midscene Java 依赖？

A: 在您的 `build.gradle` 文件中添加以下依赖：

```groovy
implementation 'com.midscene:midscene-core:1.0.0'
implementation 'com.midscene:midscene-web:1.0.0'
implementation 'com.midscene:midscene-android:1.0.0'
```

### Q: 如何配置 AI 模型 API 密钥？

A: 有三种方式配置 AI 模型 API 密钥：

1. **环境变量方式**（推荐）：
   ```bash
   export MIDSCENE_AI_API_KEY=your_api_key_here
   export MIDSCENE_AI_MODEL=gpt-4
   ```

2. **应用配置文件方式**：
   在 `src/main/resources/application.properties` 中添加：
   ```properties
   midscene.ai.api-key=your_api_key_here
   midscene.ai.model=gpt-4
   ```

3. **代码配置方式**：
   ```java
   AIModelConfig config = new AIModelConfig();
   config.setApiKey("your_api_key_here");
   config.setModel("gpt-4");
   
   AIModelService modelService = new OpenAIModelService(config);
   ```

### Q: 如何配置 Android 开发环境？

A: 请按照以下步骤配置 Android 开发环境：

1. 安装 Android Studio
2. 配置 Android SDK
3. 设置 ANDROID_HOME 环境变量
4. 启用开发者选项和 USB 调试
5. 安装 ADB 工具并确保设备已连接

详细步骤请参考 [安装配置指南](../安装配置.md#android-平台配置)。

### Q: 如何配置 Web 浏览器环境？

A: 请按照以下步骤配置 Web 浏览器环境：

1. 安装 Playwright 浏览器：
   ```bash
   mvn exec:java -Dexec.mainClass="com.microsoft.playwright.CLI" -Dexec.args="install"
   ```

2. 添加 Playwright 依赖：
   ```xml
   <dependency>
       <groupId>com.microsoft.playwright</groupId>
       <artifactId>playwright</artifactId>
       <version>1.40.0</version>
   </dependency>
   ```

## 🚀 运行时问题

### Q: 为什么我的代码运行时出现 "NoClassDefFoundError"？

A: 这通常是由于缺少必要的依赖导致的。请检查以下几点：

1. 确保已添加所有必要的依赖（core、web、android 等）
2. 检查依赖版本是否兼容
3. 如果使用 IDE，确保项目已正确刷新依赖

### Q: 为什么我的代码运行时出现 "NoSuchMethodError"？

A: 这通常是由于依赖版本不兼容导致的。请检查以下几点：

1. 确保所有 Midscene 相关依赖使用相同版本
2. 检查 Playwright 和其他第三方依赖的版本兼容性
3. 如果使用 Spring Boot，确保依赖版本兼容

### Q: 为什么我的代码运行时出现 "ConnectException" 或 "TimeoutException"？

A: 这通常是由于网络连接问题导致的。请检查以下几点：

1. 确保网络连接正常
2. 检查防火墙设置
3. 如果使用代理，确保代理配置正确
4. 检查 AI 模型 API 端点是否可访问

### Q: 为什么我的代码运行时出现 "ElementNotFoundException"？

A: 这通常是由于元素定位失败导致的。请检查以下几点：

1. 确保页面已完全加载
2. 检查元素描述是否准确
3. 尝试使用更具体的元素描述
4. 考虑添加等待时间

### Q: 为什么我的代码运行时出现 "DeviceNotConnectedException"？

A: 这通常是由于 Android 设备连接问题导致的。请检查以下几点：

1. 确保设备已通过 USB 连接
2. 确保已启用 USB 调试
3. 运行 `adb devices` 确认设备已识别
4. 检查 ADB 服务是否正在运行

## 🤖 AI 模型相关问题

### Q: 如何选择合适的 AI 模型？

A: 选择 AI 模型时需要考虑以下因素：

1. **任务复杂度**：
   - 简单任务：GPT-3.5 Turbo
   - 复杂任务：GPT-4 或 GPT-4 Turbo

2. **性能要求**：
   - 高性能要求：GPT-4 Turbo
   - 一般性能：GPT-4
   - 经济型：GPT-3.5 Turbo

3. **语言支持**：
   - 多语言支持：GPT-4 系列
   - 主要英文：GPT-3.5 Turbo

4. **成本考虑**：
   - 预算有限：GPT-3.5 Turbo
   - 预算充足：GPT-4 系列

## 📱 平台特定问题

### Q: 为什么我的 Web 自动化脚本在某些浏览器上不工作？

A: 不同浏览器可能有不同的行为和兼容性问题。请检查以下几点：

1. **确保已安装目标浏览器**：
   ```bash
   mvn exec:java -Dexec.mainClass="com.microsoft.playwright.CLI" -Dexec.args="install chromium"
   mvn exec:java -Dexec.mainClass="com.microsoft.playwright.CLI" -Dexec.args="install firefox"
   mvn exec:java -Dexec.mainClass="com.microsoft.playwright.CLI" -Dexec.args="install webkit"
   ```

2. **使用正确的浏览器类型**：
   ```java
   // Chromium
   Browser browser = playwright.chromium().launch();
   
   // Firefox
   Browser browser = playwright.firefox().launch();
   
   // WebKit (Safari)
   Browser browser = playwright.webkit().launch();
   ```

3. **添加浏览器特定的等待**：
   ```java
   // 针对 WebKit 的特殊等待
   if (browser.browserType().name().equals("webkit")) {
       page.waitForTimeout(1000);  // WebKit 可能需要更多时间
   }
   ```

4. **处理浏览器特定的弹窗**：
   ```java
   // 处理 Chrome 的通知弹窗
   page.onDialog(dialog -> {
       System.out.println("对话框文本: " + dialog.message());
       dialog.accept();
   });
   ```

   ```java
                   return operation.call();
               } catch (Exception e) {
                   lastException = e;
                   System.err.println("操作失败，尝试 " + attempt + "/" + maxAttempts + ": " + e.getMessage());
                   
                   if (attempt < maxAttempts) {
                       Thread.sleep(delayMillis);
                   }
               }
           }
           
           throw lastException;
       }
   }
   
   // 使用重试机制
   RetryHelper.retry(() -> {
       return agent.ai_action("点击按钮").get();
   }, 3, 2000);
   ```

   ```java
           }
           
           // 发送错误通知

       }
   }
   ```
